# 📊 Indian Stock Research Dashboard

An automated, **live-data** stock research dashboard for Indian equity investors. Built with Python + Streamlit, powered by Yahoo Finance.

> ⚠️ **Disclaimer:** This tool is for **educational and informational purposes only**. It is NOT financial advice. Always consult a SEBI-registered investment advisor before making investment decisions.

---

## ✨ Features

| Feature | Description |
|---|---|
| 📋 **Portfolio Overview** | Model portfolio table with live CMP, 52W high distance, scores |
| 🔬 **Detailed Analysis** | All ratios (valuation, profitability, growth, leverage, cash flow) for any stock |
| 🏆 **10-Point Scoring** | Auto-score each stock against value investing checklist |
| 🎯 **Opportunity Radar** | Visual opportunity zones, heatmaps, best-buy alerts |
| 🔍 **Screening** | Filter by ROE, D/E, sector, score — add/remove stocks dynamically |
| 📤 **Export** | Download reports as CSV or Excel |
| 📈 **Price Charts** | Interactive 1Y / 3Y / 5Y price charts |

## 🏆 10-Point Value Investor Checklist

Each stock is scored (0–10) on:

1. ✅ ROE > 15%
2. ✅ Revenue CAGR > 12% (5Y)
3. ✅ EPS CAGR > 12% (5Y)
4. ✅ D/E < 0.5
5. ✅ Positive & growing FCF
6. ✅ CFO/PAT > 1
